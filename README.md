# Sword Art Online – Web RPG

A browser-based turn-based RPG inspired by the *Sword Art Online* anime.

## How to Play

Open `index.html` in any modern browser — no build step required.

## Features

| Feature | Details |
|---|---|
| **10 Floors of Aincrad** | Each floor ends with a boss fight |
| **Turn-based combat** | Player turn → Enemy turn with phase banners |
| **Sword Skills** | 6 skills unlocked progressively by level: Horizontal, Sonic Leap, Vertical Arc, Vorpal Strike, Eclipse, Starburst Stream (16-hit!) |
| **Status effects** | Burn 🔥, Poison ☠️, Stun ⚡, Regen 💚, Drain 🩸 |
| **Enemies** | 9 regular monsters + 5 floor bosses (including Illfang, Gleam Eyes, Heathcliff) |
| **Items** | Health Potions, Mana Crystals, Elixirs — drop from enemies |
| **Leveling** | XP-based levels 1–20+, stats grow, new skills unlock |
| **Boss intros** | Cinematic intro before each boss battle |
| **Flee system** | 50% chance to escape (impossible vs bosses) |

## Files

```
index.html   – Game HTML shell
style.css    – SAO-themed dark-blue/cyan UI with animations
game.js      – Complete game engine (combat, skills, enemies, floors)
```
