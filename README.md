# Легенда о Наследии Дракона

Пошаговая браузерная RPG, вдохновлённая «Legend of Dragoon».

## Запуск

Откройте `index.html` в любом современном браузере — никаких зависимостей не требуется.

## Особенности

- **5 локаций** — Горящая Деревня, Тёмный Лес, Горные Перевалы, Логово Дракона, Небесная Крепость
- **15 обычных врагов + 5 боссов**, каждый со своей AI-тактикой
- **Пошаговая боевая система** — Атака, Магия, Предметы, Защита
- **5 заклинаний** — Огненный Шар, Ледяная Стрела, Удар Молнии, Исцеление, Душа Дракона
- **10 уровней прокачки** с ростом характеристик и разблокировкой заклинаний
- **Инвентарь** — зелья HP и эликсиры MP, случайный дроп с врагов
- **Анимации** — встряска, вспышки заклинаний, всплывающие числа урона/лечения
- **История** — 5 страниц пролога

## Файлы

| Файл | Назначение |
|------|-----------|
| `index.html` | Разметка всех экранов |
| `style.css`  | Тёмная фэнтези-тема, анимации |
| `game.js`    | Вся игровая логика (бой, карта, прогрессия) |
